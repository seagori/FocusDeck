# FocusDeck

**Firefox 데스크탑 & 안드로이드(모바일) 겸용** 집중 · 로컬 플래시카드 학습 확장프로그램(Manifest V3)입니다.  
외부 서버 통신, 추적(Telemetry) 없이 **100% 로컬(`browser.storage.local`)**에서 동작합니다.

---

## 주요 기능

### 1. 플랫폼별 알고리즘 방해 요소 제거
- **X (Twitter)**
  - 홈 타임라인의 **추천(For You) / Discover** 탭 숨김 및 **팔로우 중(Following)** 자동 전환
  - 탐색하기(Explore) 메뉴, 사이드바 트렌드/팔로우 추천, 게시글 하단 `Discover / 더 찾아보기` 블록 숨김
  - **로컬 키워드 뮤트**: 지정한 키워드가 포함된 트윗 자동 숨김
- **YouTube** (`www.youtube.com`, `m.youtube.com`)
  - 동영상 옆/아래 **알고리즘 추천 목록** 숨김
  - **YouTube Shorts** 선반 및 내비게이션 숨김 (개별 설정 가능)
- **Instagram** (`www.instagram.com`, `m.instagram.com`)
  - **홈 화면 추천 게시물** 숨김과 **탐색(Explore) 탭** 숨김을 각각 개별 설정
  - **릴스(Reels)** 메뉴 및 피드 내 릴스 숨김

### 2. 피드 & 오버레이 학습 카드 (Anki · 단순 반복 노출)
- **Anki 모드 (SM-2 간격 반복)**: 정답 가리기, 힌트 보기, `다시 / 어려움 / 보통 / 쉬움` 복습 스케줄링
- **단순 반복 노출 모드**: 앞면·이미지·발음/힌트·뜻을 한꺼번에 표시하고 `IntersectionObserver`로 실제 화면 노출 시간(초)과 횟수를 측정해 균형 있게 반복 노출
- **양방향(역방향) 복습**: 정방향 / 역방향 / 양방향 랜덤 선택
- **한자 읽기(후리가나) 가리기/보이기 토글**: `約束（やくそく）` 형태에서 읽기를 가리고 한자만 먼저 확인 가능
- **모든 언어 TTS 음성 읽기**: 일본어·한국어·영어·중국어 등 자동 언어 감지 기반 로컬 `speechSynthesis` 발음 지원
- **이미지 카드 지원**: 이미지 URL 또는 로컬 이미지 파일 업로드(브라우저 내 리사이즈/압축 후 로컬 저장)
- **플랫폼별 노출**:
  - **X**: 피드 트윗 사이 인라인 삽입
  - **YouTube**: 동영상 옆 추천 자리 패널(`다음 카드` 버튼 포함) + 쇼츠 일정 주기 플로팅 카드
  - **Instagram**: 일정 시간(`overlayCardIntervalSec`, 기본 60초)마다 자동 교체되는 플로팅 오버레이 카드 + 검색(`/explore`) 그리드 위 정사각형 플로팅 카드(타일이 스크롤되어 사라지면 자동 닫힘)

### 3. 사용 시간 추적 & 학습 통계
- **사용 시간 체크**: X · YouTube · Instagram 활성 사용 시간을 설정 주기(기본 **3초**)마다 로컬에 누적
- **사용 시간 알림**: 설정 간격(기본 **20분**)마다 굵은 폰트의 사용 시간 + 오늘의 학습 현황 알림 카드 표시
- **일일 학습 목표 & 연속 일수(Streak)**: 오늘 복습 수, 목표 달성 여부, 연속 달성 일수 표시

### 4. 대용량 카드 · 덱(그룹) 관리
- **1만 개 이상 카드 최적화**: 복습 일정(`srsProgress`)·노출 기록(`exposureProgress`) 분리 저장, 50개 단위 페이지네이션, 180ms 검색 디바운스
- **덱(그룹)별 관리**: 총 카드 수/복습 가능 수 확인, **플랫폼 지정(`모든 플랫폼` / `X 전용` / `YouTube 전용` / `Instagram 전용`)**, 덱별 가중치, 그룹 이름 변경, 일괄 삭제
- **가져오기 / 내보내기 / 백업**: Anki TSV(`앞면\t뒷면\t힌트\t태그\t이미지`), `::` 구분, JSON 가져오기(중복 건너뛰기 옵션) 및 전체 JSON 백업/복원

### 5. 다국어 UI
- **자동(브라우저) / 한국어 / English / 日本語** 지원

## 설치 방법

### Firefox 데스크탑
1. 주소창에 `about:debugging#/runtime/this-firefox` 입력
2. **임시 부가 기능 로드(Load Temporary Add-on...)** 클릭 → `manifest.json` 선택

### Firefox 모바일 (Android)
- 서명받은 `.xpi`를 내려받은 뒤, 안드로이드 Firefox **설정 → Firefox 정보(로고 5번 탭) → 파일에서 부가 기능 설치**로 설치

## 권한 및 개인정보 보호
- **`permissions`**: `["storage"]`만 사용 (외부 네트워크 전송 없음)
- **`host_permissions`**: `x.com`, `twitter.com`, `youtube.com`, `instagram.com` 도메인으로 한정
- **`data_collection_permissions`**: `required: ["none"]`
